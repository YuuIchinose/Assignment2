# Mystic Forest Adventure

Mystic Forest Adventure is a musical composition inspired by RPG games. I used code to create music that feels like exploring a magical forest. The music is gentle, slightly mysterious and adventurous, but not scary. I also created a short animation to make the project more interesting.

## General Information

I have loved RPG games since I was a child, and I have always wanted to create my own game. However, I don't have enough technical skills to make a full game yet, so I decided to start with music.

The idea of my project is to create background music for a magical forest in an RPG game. I wanted the music to feel peaceful and a little mysterious, like the beginning of an adventure.

Through this project, I also wanted to learn how to use coding to create music and experiment with different sounds.

The main focus of this project is the music I created using TunePad. I also made a short animation to make the presentation more interesting and help people imagine the forest adventure. The animation is only a visual addition, while the TunePad music is the main part of my project.(All the characters and animations were drawn by myself personally, without using AI to generate them.)

## Technologies Used

- TunePad – for coding and creating music
- Python – for writing the music code
- GitHub – for storing and sharing my project

## Features

- Original RPG-inspired background music
- Different instruments used for melody and harmony
- A gentle and slightly mysterious forest atmosphere
- Changes in rhythm and melody to make the music more interesting
- A short animation to accompany the music

## Setup

1. Open [TunePad](https://tunepad.com/).
2. Open or import the project files.
3. Run the code to generate the music.
4. Play the composition to hear the final result.

## Usage

This project is mainly made for listening and demonstrating how music can be created through code.

The music is designed as background music for an RPG-style forest adventure. It can also be played together with the short animation.
